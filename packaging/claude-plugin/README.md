# Beankeeper for Claude Code and local Cowork

Ask your agent to set up your books, record what changed, and answer questions
about your money. Your encrypted books stay on your computer. The plugin includes
the Beankeeper guide and connects to the installed Beankeeper Desktop executable.
Install Beankeeper Desktop using its graphical installer first. The host must be
able to find `bk` on its executable search path. If the connection fails, ask your
agent or support to check that installation and the host environment.

Upload `claude-plugin.zip` using Customize > Plugins > Add > Upload plugin.
The local server works in Claude Code and Cowork sessions running on your
computer. Chat ignores this plugin's local server; use the signed `.mcpb`
extension for Claude app chat. There is no cloud connector in this plugin.
